跑完整段动作，有多难？

从 run1_subject5 的第 0 帧跟踪到末帧，要连续走 11889 个控制步。64 个仿真环境各跑一次，中途摔倒或提前超时都算失败。

T7 还需要和参考策略比较

这是截至 2026-11-18 记录的阶段结果。还要让 SuperMimic 的策略按相同条件跑同一段动作，比较全程成功率和平均跟踪误差，再由用户确认验收阈值。

4096 个环境一起训练占多少显存？

T0–T6 已通过验收。T6 在 RTX 5060 Ti 上用 2048 个环境训练了 50 次迭代，测得整张显卡的最高显存占用为 4610 MiB。默认配置已改为 4096 个环境，完整训练的显存峰值仍待实测。

导出和回放验证到了哪一步？

T9 已在 Mac 的 CPU 上验证了虚影回放。T8 已在 CPU 上核对 ONNX 的输出。等 T7 的策略通过验收，还要做 sim2sim 测试，用导出的 ONNX 在仿真中跟踪整段动作，全程不摔倒才算通过。
