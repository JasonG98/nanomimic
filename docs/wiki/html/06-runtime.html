训练结束后，哪些部分还在工作？

回放时，半透明的 G1 显示世界模型预测的姿势。它和仿真中的 G1 越走越远，就说明预测误差在累积。导出的 ONNX 文件包含 Actor 和参考动作库。

ONNX 的两个输入

obs
[1, 93H + 640]。最近 H 帧观测按传感器分组输入，图内再按帧排列。Actor 结合目标输出关节指令 actions [1, 29]。
time_step
[1, 1]。按帧号读取关节角度和角速度，以及各部位的位置、朝向四元数、线速度和角速度。

哪段动作能导出？

导出时读取检查点指定的动作文件，最多支持 15000 帧。40 段合并后共 441120 帧，超过上限。查询时，负帧号取首帧，超过末尾取末帧。

导出后怎样核对结果？

--verify 在 CPU 上比较 ONNX 和 PyTorch 的关节指令，最大绝对误差须小于 10⁻⁴。还会检查六组参考数据是否与动作库逐项相等。能否跑完全程，要在仿真里检验。
