训练结束后，哪些部分还在工作？

回放同时运行物理仿真和世界模型，用虚影观察预测怎样偏离。导出则把做决策的 Actor 和一份参考动作库装进 ONNX。

ONNX 的两个入口

obs
调用方提供 [1, 93H + 640]。图内把按传感器分组的历史转成按帧排列，Actor 输出 actions [1, 29]。
time_step
形状 [1, 1]，只查询内嵌动作库。返回关节位置、速度，以及部位的位置、四元数、线速度、角速度。

哪段动作能导出？

导出读取检查点配置中的动作文件，总帧数上限 15000。查询时间会被限制在有效帧内。40 段合并训练库共 441120 帧，超过上限。

导出自检看什么？

--verify 在 CPU 上比较动作误差（要求 <10⁻⁴），并逐元素核对六项参考量。完整动作的 ONNX 闭环跟踪另行验收。
