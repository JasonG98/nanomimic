快要摔倒，未来还值多少分？

想象中的一步既要评估动作像不像，也要估计 G1 还能撑多久。越接近失衡，后面那些好动作对当前决策的分量就越轻。

先给姿势打分

骨盆位置和朝向在世界坐标系直接比较。比较各部位姿态时，先把参考动作的水平位置和偏航对齐到预测骨盆，保留参考的高度与倾斜。

再看运动是否顺畅

另外比较各部位的线速度、角速度，扣除动作突变与关节越限。六项正奖励的权重合计 5，乘控制步长后每步上限为 0.10。

把 32 步合成一次回报

每步奖励乘以时间折扣及此前累积的存活概率。末端再加上同样折扣后的价值估计，Actor 据此更新。价值网络（Critic）读取 68 维状态、640 维目标和 33 维环境信息，以广义优势估计（GAE）构造训练目标。
